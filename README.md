# 心魂工作台 · Xinhun Workspace

一款**只在自己电脑上运行**的个人工作台。把任务计划、图文记录、常用软件启动器收进同一个本地窗口，数据存在自己的 SQLite 文件里，不注册账号、不依赖云数据库。

- 默认只监听本机 `127.0.0.1`
- 业务数据保存在独立 SQLite 文件中，刷新页面、关闭浏览器、重启电脑都不会丢
- 自带便携 Node 运行时，目标电脑**无需安装 Node**
- 用 Edge 独立窗口（`--app`）展示，观感接近原生桌面软件

当前版本：**v1.0.0**

---

## 主要功能

### 任务计划
- 大学课表式的 **7 天 × 8 时段**周计划网格
- 3 种编辑模式：全局 / 本周 / 自定义周期，每个时间块可单独切换
- 周次分页 + 年份月份快速跳转（跨年周次按"本年最后一周"规则计算）
- 日历：法定节假日（休/班）、24 节气、点击日期写备注（备注独立于时间块）
- 时间块内任务勾选、备注、字号按任务数量自适应
- 过去周次只读

### 记录台
- 一个板块 = **左侧图片区（最多 4 张，2×2）+ 右侧文字**，左图右字
- 三种加图方式：点「加图」、拖图到指定板块、`Ctrl+V` 粘贴到鼠标所在板块
- 板块可拖拽排序、复制、删除；图片可单独移除
- 文字支持轻量 **Markdown**（标题 / 列表 / 代码块 / 粗体 / 行内代码 / 链接），可切换编辑/预览
- 每个板块可加**标签**，随板块保存并可被全文搜索命中

### 启动台
- 把常用软件、文件夹做成图标网格，一键启动
- 支持拖入 `.lnk` / `.url` 快捷方式自动解析目标路径
- 原生「选文件夹 / 选文件」对话框，直接拿到完整路径
- 自动提取 `.exe` 图标，也可上传自定义图标（只影响显示）
- 分类夹：可命名 / 重命名 / 右键删除 / 拖动排序，图标可直接拖进分类夹
- **双击启动**（防止误触），带图标跳动动画 + 清脆启动音
- 图标悬停可「以管理员身份运行」（走 UAC）

### 自媒体
- 内容灵感 → 制作 → 发布的创作流程看板
- 发布后数据（播放 / 点赞 / 评论）记录与趋势图表

### 数据与设置
- 手动保存、自动备份（保留最近 30 份）、备份恢复、ZIP 导出
- **数据体检**：完整性检查 + `optimize` + `VACUUM`
- 回收站：恢复 / 永久删除 / 一键全部删除
- 界面：Liquid Glass / Notion 笔记 / Neo-Brutalism 三种风格 × 明暗主题
- 强调色（5 色）、界面字号（小/标准/大）
- 自定义背景图、**背景透明**（透出桌面动态壁纸，带程度滑块）
- 开机自启、**启动时全屏**（最大化保留任务栏，还原回到设定尺寸）
- 启动默认打开「启动台」

## 快速开始（Windows）

### 方式一：便携版（推荐给使用者）

1. 解压发布包到任意目录（不要放在需要管理员权限的路径）
2. 双击 `心魂工作台.exe`
3. 首次启动会自动生成 `data/` 数据目录并打开窗口

> 整个文件夹可整体拷贝到其他 Windows 电脑使用。

### 方式二：源码运行（开发者）

需要 Node.js **>= 22.13**。

```bash
npm install
npm run build
npm run app:start     # 启动本地服务并打开窗口
```

> macOS / Linux 也可用 `npm run dev` 进行前端开发，但窗口封装与系统级功能（开机自启、窗口透明度、资源管理器）目前面向 Windows。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 19 + Vite 7 + TypeScript + react-router + TanStack Query |
| 后端 | Node + Fastify 5 + better-sqlite3 |
| 数据库 | SQLite（单文件，WAL 模式） |
| 外壳 | C# 启动器 + 便携 Node 运行时 + Edge `--app` 独立窗口 |

## 目录结构

```
src/                前端（pages / components / features）
server/             后端（Fastify 路由、SQLite store、系统集成）
database/migrations 数据库迁移（按序号执行）
scripts/            启动与打包脚本（start-app / platform / package-portable）
public/             静态资源（模块图标等）
dist/ dist-server/  构建产物（不入库）
data/               运行数据（不入库）
```

## 数据与备份

- 数据文件：`data/data/app.sqlite`
- 自动备份：`data/backups/`（保留最近 30 份）
- 恢复：数据与设置 → 备份与恢复 → 选择备份 → 恢复（恢复前会先为当前数据创建安全备份）
- 也可用「数据体检」做完整性检查与空间回收

## 开发脚本

```bash
npm run dev          # 前后端并行开发
npm run build        # 类型检查 + 前端构建 + 服务端编译
npm run lint         # ESLint
npm run test         # Vitest
npm run app:start    # 生产模式启动（构建后）
```
