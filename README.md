# 心魂工作台 · Xinhun Workspace

> 一款只在自己电脑上运行的**本地个人工作台**。把任务计划、图文记录、常用软件启动器收进同一个窗口，数据保存在本机 SQLite 文件里，不注册账号、不依赖云服务。

**当前版本：v1.0.0** · 平台：Windows（便携版）· 许可：MIT

## 它是什么

- **完全本地**：默认只监听 `127.0.0.1`，业务数据在 `data/data/app.sqlite`，断网可用。
- **独立窗口**：用 Edge `--app` 模式打开，无地址栏无标签页，观感接近原生桌面软件。
- **便携运行**：自带 Node 运行时，目标电脑**不需要安装 Node**；整个文件夹拷走即用。
- **可定制**：三种界面风格 × 明暗主题、5 种强调色、三档字号、自定义背景或透出桌面壁纸。

| 模块 | 一句话说明 |

## 模块一：任务计划

课表式的时间规划，一天分 8 个时段、一周 7 天。

- **周计划网格**：7 天 × 8 时段，点击任意格子编辑任务。
- **三种编辑模式**：全局 / 本周 / 自定义周期，可对每个时间块单独指定；也可设置"本省默认编辑模式"。
- **周次管理**：上一周 / 下一周 / 回到本周；年份与周次快速跳转。
  - 周次规则：本年最后一周即为最后一周（可跨年）；其余年份以"第一个周一"为第一周。
- **历史保护**：过去周次只读，避免误改。
- **任务能力**：一个时间块可放多个任务，带勾选完成状态、备注；字号按任务数量自动递减（1 个最大，多个逐级变小，不溢出）。
- **日历侧栏**：
  - 法定节假日标注（休 / 班）；
  - 24 节气显示；
  - 点击日期写**简单备注**（独立于时间块，显示在日历上）。
- **外观**：时间块为毛玻璃质感，背景冲突时也能看清文字。

## 模块二：记录台

按项目组织的图文记录，一个板块 = 一张图（或最多四张）+ 一段文字。

- **左图右字**：左侧图片区、右侧文字区，对照查看。
- **单块最多 4 张图**：2×2 排布，可单张移除。
- **三种加图方式**：
  1. 点板块里的「加图」格（只加到该板块）；
  2. 从桌面/文件夹**把图片拖到指定板块**，松手前该板块会高亮；
  3. 鼠标悬停在某板块上按 **Ctrl+V**，粘贴到该板块。
- **文字**：
  - 支持轻量 **Markdown**：标题、列表、代码块、粗体、行内代码、链接；
  - 底部可一键切换 **编辑 / 预览**。
- **标签**：每个板块可加多个标签（回车添加、点击移除），随板块保存，可被全文搜索命中。
- **板块管理**：上移 / 下移 / 删除；项目可新建、重命名、删除。
- **图片查看**：点图可放大查看。

## 模块三：启动台

把常用软件和文件夹做成图标网格，快速启动。

- **快捷方式网格**：图标 + 名称，分类夹过滤。
- **多种添加入口**：
  - 手动填写名称与路径；
  - **原生「选文件夹 / 选文件」对话框**，直接拿到完整路径；
  - **拖入 `.lnk` / `.url` 快捷方式**，自动解析目标路径；
  - 拖入桌面上文件夹时，按名称在桌面/文档/下载等常见位置反查路径。
- **图标**：
  - `.exe` 自动提取关联图标；
  - 可上传自定义图标（仅影响启动台显示，不改软件本身图标）；
  - 文件夹使用文件夹图标。
- **启动方式**：
  - **左键双击启动**（防止单击误触）；
  - 启动时图标有一个**轻跳动画**和一声**短促清脆的提示音**；
  - 悬停图标有「**以管理员身份运行**」（走 UAC 确认）。
- **分类夹**：
  - 可新建、**右键重命名 / 删除**；
  - 支持**拖动左右调整顺序**；
  - 图标可**直接拖进分类夹**完成归类；
  - 分类夹为暗色毛玻璃卡片，只有名字区域触发切换。
- **排序**：图标可拖动调整前后顺序，顺序持久保存。
- **新增归属**：切到某分类后新增的项自动归入该分类（「全部」下新增则默认未分类）。

## 模块四：自媒体

内容创作的流程记录。

- **阶段看板**：灵感 → 待策划 → 制作中 → 待发布 → 已发布。
- **内容条目**：标题、平台、内容形式、计划发布时间、文案、素材路径、发布链接等。
- **发布后数据**：播放、点赞、评论记录，支持趋势图表查看。
- **统计**：正在制作、等待发布、本月已发布等概览指标。

## 模块五：数据与设置

数据管理与个性化。

**数据管理**
- 手动保存（顶栏按钮 / 自动保存状态提示）。
- **备份**：每天自动备份一次，普通备份保留最近 30 份；可立即备份、命名、标记"长期保留"。
- **恢复**：选择任一备份恢复（恢复前自动为当前数据再备份一份）。
- **导出**：生成包含 JSON 与各模块 CSV 的 ZIP。
- **数据体检**：`integrity_check` 完整性检查 + `optimize` + `VACUUM` 空间回收（启动时也会自动 optimize）。
- **回收站**：删除先进回收站，可恢复 / 永久删除 / **一键全部删除**。

**外观**
- 界面风格：Liquid Glass / Notion 笔记 / Neo-Brutalism。
- 界面主题：浅色 / 深色（**默认深色**）。
- **强调色**：青、紫、翡翠、琥珀、玫瑰（影响按钮、高亮、选中态）。
- **界面字号**：小 / 标准 / 大（**默认大**）。
- 背景图片：可上传自定义背景。
- **背景透明**：默认开启（程度 240），透出桌面动态壁纸，优先级高于自定义背景图。

**启动与窗口**
- **开机自启**：登录 Windows 时自动启动。
- **启动时全屏**：最大化但保留任务栏；点"还原"回到设定尺寸（1317×853）。

## 顶栏与系统集成

顶栏右侧有一排系统快捷按钮：

| 按钮 | 行为 |
|---|---|
| 房子 | 打开资源管理器（此电脑） |
| 下载 | 打开 `%USERPROFILE%\Downloads` |
| 图片 | 打开 `%USERPROFILE%\Pictures` |
| 音乐 | 打开 `%USERPROFILE%\Music` |
| 齿轮 | 打开控制面板 |
| 电源 | 关机（10 秒倒计时，带二次确认） |

- 「下载 / 图片 / 音乐」三个按钮的**名称与路径可在「数据与设置 → 顶栏快捷方式」里自定义**，支持原生选文件夹；
- 顶栏还有：全局搜索（`Ctrl+K`）、手动保存、保存并退出、自动保存状态。

## 细节设计

这些是散落在各处、但影响日常手感的小设计：

**导航**
- 左侧导航**右键即可重命名**，新名字同步到顶栏标题和页面大标题；
- 导航分组支持**拖动排序**，顺序会记住；
- 窗口尺寸/位置变化后布局自适应。

**记录台**
- 单块图片最多 4 张，**"加图"只加到被点的那个板块**（不会跑到最后一块）；
- 拖图时目标板块**高亮描边**提示落点；
- `Ctrl+V` 粘贴按**鼠标所在板块**分配，避免粘错位置；
- Markdown 底部一键 **编辑 / 预览** 切换；
- 标签**点击即移除**，回车即添加。

**启动台**
- **双击才启动**（单击只选中），配图标轻跳 + 清脆音效，防误触也确认反馈；
- 启动时自动把目标窗口提到前台，工作台层级**保持不动**（不会把别的窗口一起顶上来）；
- 分类夹、图标都支持拖动重排；
- 支持 `%USERPROFILE%` 这类环境变量路径（换电脑不用改）。

**窗口与外观**
- 「启动时全屏」是**最大化但保留任务栏**，点还原精确回到 1317×853；
- 背景透明度可调（170–255），越大文字越清晰、壁纸越淡；
- 目标窗口从后台拉起时，会尝试**抢到前台**（绕过 Windows 前台锁定）。

**数据**
- 数据体检会真的回收空间（实测一次回收 640KB）；
- 回收站支持"一键全部删除"，且删除前二次确认。

## 数据、备份与安全

- 数据文件：`data/data/app.sqlite`（SQLite，WAL 模式）。
- 备份目录：`data/backups/`。
- 备份、恢复、导出都在「数据与设置」中完成，不依赖云端。
- 删除操作先进入回收站，永久删除需要再次确认。

## 技术栈与目录结构

| 层 | 技术 |
|---|---|
| 前端 | React 19 + Vite 7 + TypeScript + react-router + TanStack Query |
| 后端 | Node + Fastify 5 + better-sqlite3 |
| 数据库 | SQLite（单文件，迁移按序号执行） |
| 外壳 | C# 启动器 + 便携 Node 运行时 + Edge `--app` 窗口 |

```
src/                前端（pages / components / features）
server/             后端（Fastify 路由、SQLite store、系统集成）
database/migrations 数据库迁移
scripts/            启动与打包脚本
public/             静态资源
dist/ dist-server/  构建产物（不入库）
data/               运行数据（不入库）
```

## 快速开始

### 便携版（推荐使用者）

1. 解压发布包到任意目录（避免需要管理员权限的路径）；
2. 双击 `心魂工作台.exe`；
3. 首次启动自动生成 `data/` 并打开窗口。

整个文件夹可拷贝到其他 Windows 电脑使用。

### 源码运行（开发者，需 Node ≥ 22.13）

```bash
npm install
npm run build
npm run app:start
```

其他常用脚本：`npm run dev`（并行开发）、`npm run lint`、`npm run test`。

## 已知限制

- **平台**：窗口封装、开机自启、窗口透明度、资源管理器等系统级功能目前仅支持 Windows。
- **界面外壳**：本质是"本地服务 + 浏览器内核窗口"，不是 Qt/WinUI 原生界面。
- **exe 未签名**：首次运行可能被 SmartScreen 提示"未知发布者"。
- **无安装包**：目前为便携 zip 形式。
- **背景透明**：受浏览器限制只能整窗调透明度（文字/图标会一起变淡），不是逐像素透明。
- **单用户本地**：无账号体系、多人协作、云同步。
